## 🎯 Sobre el curso

**Ethical Hacking** es un curso práctico enfocado en metodologías de evaluación de seguridad (pentesting) sobre aplicaciones web, cubriendo desde la planificación y el reconocimiento hasta la explotación, post-explotación y elaboración de informes técnicos, siguiendo marcos de referencia como **OWASP Testing Guide** y **OWASP Top 10**, y sistemas de calificación de severidad como **CVSS**.
